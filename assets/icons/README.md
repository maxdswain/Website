# Site icon sources

Technology icons are third-party brand marks, not original site artwork. Their inclusion identifies technologies used; it does not imply endorsement. Trademark rights remain with their respective owners.

## CV skill icons

The `skill-*.svg` files below come from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), distributed under [CC0](licences/simple-icons-CC0.txt):

- `python`, `go`, `typescript`, `gnubash`, `c`, `haskell`
- `vllm`, `haystack`, `modelcontextprotocol`, `pydantic`
- `linux`, `kubernetes`, `argo`, `prometheus`, `grafana`, `sentry`, `cloudbees`, `jenkins`, `githubactions`
- `fastapi`, `postgresql`, `mongodb`, `elasticsearch`

Source URLs follow `https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/SLUG.svg` using the names above. These are monochrome representations of the technology marks; fill is set to `currentColor` for light/dark contrast. SVG titles are omitted and icons hidden from assistive technology because every pill includes a visible text label.

`skill-azure.svg` and `skill-grpc.svg` come from [Devicon](https://github.com/devicons/devicon), under the [MIT License, Copyright (c) 2015 konpa](licences/devicon-MIT.txt):

- https://github.com/devicons/devicon/blob/master/icons/azure/azure-plain.svg
- https://github.com/devicons/devicon/blob/master/icons/grpc/grpc-plain.svg

Their fills are adapted to `currentColor`. The Azure mark is also used to identify the Azure platform in the Azure AI Foundry pill; it is not a distinct Foundry logo.

`skill-deepeval.svg` is the [official DeepEval icon](https://github.com/confident-ai/deepeval/blob/main/docs/public/icons/deepeval-icon.svg) from Confident AI's [Apache-2.0-licensed repository](licences/deepeval-Apache-2.0.txt). Its artwork is unchanged; accessibility attributes are added to the SVG root.

`skill-sglang.svg` is the [official SGLang square logo](https://github.com/sgl-project/sglang/blob/main/assets/logo_square.svg) from its [Apache-2.0-licensed repository](licences/sglang-LICENSE.txt). `skill-docling.svg` is the [official Docling logo](https://github.com/docling-project/docling/blob/main/docs/assets/logo.svg) from its [MIT-licensed repository](licences/docling-LICENSE.txt). Artwork and embedded images are preserved; SVG IDs are namespaced, decorative accessibility attributes are added, and SGLang's viewBox is set from its original dimensions for responsive sizing.

The Pydantic family mark identifies Pydantic AI. The combined GlitchTip / Sentry pill uses Sentry's mark to represent the Sentry-compatible monitoring tooling, not a separate GlitchTip logo.

Docker uses Blowfish's bundled Docker icon. GraphRAG and graph databases use its generic `fork` icon, and CI/CD uses `list-check`; these are concept indicators, not official product logos.
